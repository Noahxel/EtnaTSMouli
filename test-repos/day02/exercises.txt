Exercice 04 - forEach

Les prénoms et noms ont été saisis en minuscules, ce qui n'est pas professionnel pour l'affichage. Vous devez normaliser ces données : mettre une majuscule à la première lettre du prénom et transformer le nom de famille complètement en majuscules, comme on le voit souvent dans les documents officiels ou les badges d'identification.

La méthode forEach permet de modifier directement les objets existants dans le tableau. C'est particulièrement utile quand vous voulez mettre à jour des données en place sans créer de copies supplémentaires en mémoire.

Exercice 11 - nothing
Dans ce onzième exercice, vous allez explorer les types spéciaux de TypeScript : null, undefined, unknown, et void.
Ces types ne représentent pas des données classiques, mais des états particuliers : absence de valeur, type inconnu, ou fonction ne retournant rien.
Bien les comprendre permet d'écrire un code plus sûr et d'éviter des erreurs logiques subtiles.

Imaginez que vous travaillez sur une petite application interne de monitoring à l'ETNA.
Certains capteurs peuvent :

Renvoyer une valeur numérique (number),
Ne pas encore être initialisés (undefined),
Etre déconnectés (null),
Ou retourner un type inconnu si la donnée n'a pas été validée (unknown).
De plus, certaines fonctions système ne retournent jamais (par exemple lorsqu'elles lèvent une erreur) et retourne le type never, tandis que d'autres ne retournent rien du tout (void), comme une simple fonction de log.

Cet exercice vous permettra de distinguer les usages de ces types spéciaux à travers des cas concrets.

Consignes
Créez une fonction getUserName pour qu'elle :
prenne un paramètre user de type { name?: string }
retourne undefined si user.name n'est pas défini
retourne une chaîne "Anonymous" si user.name vaut null
retourne le nom sinon.
Créez une fonction processValue :
prend un paramètre value de type unknown
si value est une chaîne de caractères, affiche sa longueur
si value est un nombre, affiche sa valeur multipliée par 2
sinon, affiche "Type non reconnu"
Implémentez une fonction logMessage :
prend un paramètre message de type string
ne retourne rien (void)
affiche le message dans la console.
Testez les trois fonctions avec différents cas pour observer les comportements.
En lançant ceci :

console.log(getUserName({ name: "Alice" }));
console.log(getUserName({}));

console.log("\n=== Test processValue: ===");
processValue("Hello");
processValue(21);
processValue(true);
processValue({ key: "value" });

console.log("\n=== Test logMessage: ===");
logMessage("Ceci est un message de test");
logMessage("TypeScript est génial !");
L'exemple attendu dans le termine est :
